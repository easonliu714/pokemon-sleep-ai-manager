使用說明

兩種更新方式

少量修正：直接在食材、道具或寶可夢詳情頁編輯並儲存。
批次更新：使用更新中心的情境提示詞產生 JSON，再執行結構檢查、Dry Run 與套用。

多張截圖上傳建議

如有多個遊戲畫面截圖需要交給 AI 解析，建議先壓縮成 ZIP 檔再一次上傳。請保留清楚且不重複的檔名或編號，讓 AI 能在 evidence.source_image_ref 中正確對應每張來源畫面。

支援情境

資料安全

公版主檔只包含遊戲共用名稱與配方；寶可夢、庫存數量、解鎖狀態與容量只存在目前瀏覽器。每次手動儲存與 JSON 套用前都會建立快照，請定期下載 SQLite 或完整 JSON。
